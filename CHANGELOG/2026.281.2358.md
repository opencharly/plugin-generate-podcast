## Summary

The desk's remaining half, in ONE change: the eight resolver leaves the goal names, the
renderer's input validation with the typed stage outputs, and the `generate-podcast` skill
itself — plus the schema defect this work uncovered, fixed with the fixtures that would have
caught it.

* **The resolver layer** (`resolvers.go`): `file`, `glob`, `git-log`, `issues`, `prs`, `doc`,
  `doctrine`, `episode` — one adapter per word of the schema's `#Resolver` vocabulary, plus the
  existing `changelog-window` walk carried into the same `<resolver>:<ref>` grammar. Every
  adapter is reachable from the shipped command (`generate-podcast resolve --source ...`), and a
  test keeps the adapter table and the published vocabulary equal in BOTH directions.
* **Input validation + typed outputs** (`validate.go`, `schema/episode.cue`): `#Claim` and
  `#TypedOutputs` are authored in CUE first and the Go is regenerated. The new `validate` leaf
  gates the writing stage's output against the bundle — every claim's quote must appear VERBATIM
  in the source it cites (the anti-fabrication gate), the coverage numbers must match the bundle
  (and the selection when one is supplied), and a window with tag gaps must state them. `emit
  --bundle` is the renderer's input gate: an episode citing a source outside its bundle cannot
  reach the cue lines.
* **The skill**: the canonical text now lives as a `skill:` entity in the candy that owns it,
  with `sources`/`voice` references, so the marketplace projection is a refs-pin bump rather than
  a copy. The content is the plan's canonical text, copied byte-for-byte modulo two documented
  substitutions (the address becomes `/charly-tools:generate-podcast`, and the plan-internal
  `(§2d)` pointer is dropped).
* **Security (validator round 1, T3)**: the first revision attached `GITHUB_TOKEN` to every
  HTTP request, and `Deps.get` also serves `doc:`'s arbitrary-URL branch — so a
  `doc:https://any-host/…` ref shipped the operator's credential to a host the ref chose. The
  credential is now scoped to the API base host (`sameHost`; an unparseable URL never qualifies)
  and plaintext `http://` documents are refused outright. Two tests assert the header on the API
  host and its ABSENCE on any other host — they read the bytes that would have left the process.
* **The defect this uncovered**: the length rules were decoration. `_min: len(x) >= 1` evaluates
  to the boolean VALUE `false`, which CUE accepts, so `#SourceBundle`'s one-source rule and
  `#Episode`'s three-segment floor rejected nothing; and the documented alternative
  (`& [_, ...]`) inlines an anonymous element type into the generated Go. Both are replaced by the
  prefix-list form (`[#Source, ...#Source]`), which rejects the empty list AND keeps `[]Source`.
  The segment CEILING cannot be expressed that way, so it is a Go guard — stated as such. Four
  reject arms now prove each rule binds, one rule per arm.

This PR supersedes #5, which the validator auto-closed at its five-verdict bound. Every finding
from those five rounds is fixed in this branch, and each fix is the kind that would otherwise have
shipped: (1) the `doc:` resolver sent `GITHUB_TOKEN` to any host a ref named — now scoped to the API
host, with two tests reading the transmitted header; (2) an overclaiming `Emit` comment — now matches
its guard; (3) a `splitRef` guard that did not do what its comment promised, and later a duplicate
copy of that comment left behind — the guard is explicit and the stale block is gone; (4) a stated
test count that contradicted the pasted count — the number is now read from the run that produces the
output; (5) an id-collision assertion that passed only via an unrelated error — rewritten to drive a
real collision, with the falsification measured below; (6) a reject arm whose note still named the
deleted inert `_min` as the live gate — corrected, and every sibling arm and schema note swept for
the same tense.
